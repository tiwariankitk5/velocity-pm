# Roadmap

## Phase 1: Foundation

- Monorepo setup
- Auth API
- Workspace, project, task API
- Dashboard shell
- Docker Compose

## Phase 2: Real Product Workflows

- Invite acceptance
- Role management UI
- Kanban drag and drop
- Comments and activity history
- Notifications
- File uploads

## Phase 3: Realtime Collaboration

- Workspace chat persistence
- Typing indicators
- Presence sidebar
- Live board updates
- Notification center

## Phase 4: AI Features

- Generate task descriptions
- Summarize meetings
- Auto-create sprint plan
- Generate documentation
- AI review notes

## Phase 5: Production Readiness

- Full refresh token rotation
- OAuth
- 2FA
- Unit and integration tests
- Load testing
- CI/CD deployment
- Monitoring and error tracking
